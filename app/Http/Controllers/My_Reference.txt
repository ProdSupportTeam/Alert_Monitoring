Step 1: Configure in .env
DB_CONNECTION=mysql   # default (alerts DB)

RO_DB_CONNECTION=mysql_ro
RO_DB_HOST=xxx.xxx.xxx.xxx
RO_DB_DATABASE=orders_db
RO_DB_USERNAME=readonly_user
RO_DB_PASSWORD=*****

------------------------------------------------

Step 2: Update config/database.php

Add new connection:

'mysql_ro' => [
    'driver' => 'mysql',
    'host' => env('RO_DB_HOST'),
    'database' => env('RO_DB_DATABASE'),
    'username' => env('RO_DB_USERNAME'),
    'password' => env('RO_DB_PASSWORD'),
    'charset' => 'utf8mb4',
    'collation' => 'utf8mb4_unicode_ci',
],

-----------------------------------
🚀 Step 3: Use Connections in Code
✅ Orders → use RO DB
DB::connection('mysql_ro')->table('orders')

----------------------------------

✅ Alerts → use default DB
DB::table('alerts_log')
